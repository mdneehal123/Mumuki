# mumuki.in — MUMUKI India

Website for MUMUKI India (Honey Banana PDRN Korean skincare), imported and marketed in India by Beauty Mart Pvt Ltd.

- `index.html` — main site (products, gallery, videos, launch list)
- `privacy.html`, `terms.html`, `shipping.html`, `returns.html` — policy pages
- `images/` — product photos and video
- `SETUP-GUIDE.md` — how to connect the sign-up Google Sheet, Google Analytics, Meta Pixel and Search Console
- `google-sheet-script.gs` — Apps Script for saving launch-list sign-ups

Static site: no build step. Upload the files to any web host, or enable GitHub Pages.
